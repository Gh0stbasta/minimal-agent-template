# Agent Registry

## Architect

Use when:

- Initial architecture is required
- A new feature package must be created
- Architecture rework is required
- Technical feature dependencies must be evaluated

Expected output:

- Architecture report
- Feature package
- ADRs
- Dev handover

---

## Development

Use when:

- A feature is ready for implementation
- Review findings require code changes
- Test findings require code changes

Expected output:

- Implemented feature
- Development report
- One commit per ticket
- Reviewer handover

---

## Reviewer

Use when:

- Development reports feature completion
- Development rework has been completed

Expected output:

- Review report
- Request for changes
- Testing recommendation
- Architecture escalation

---

## Test

Use when:

- The implementation has passed review
- Independent validation is required

Expected output:

- Test implementation
- Test results
- Defect findings
- PR readiness recommendation

---

## PR

Use when:

- Development, review, and test evidence are complete
- A merge package must be prepared

Expected output:

- PR report
- Dashboard update
- PR description
- Business handover

---

## Business

Use when:

- Business analysis is requested
- A feature request should be proposed
- A human-approved roadmap change must be recorded
- A PR requires business assessment before merge

Expected output:

- Business report
- Feature request
- Roadmap update
- Merge recommendation
