
# Technical Debt

## Purpose

This document tracks known technical debt within the project.

Technical debt represents compromises, shortcuts, missing improvements, architectural limitations, or deferred work that may impact maintainability, reliability, security, scalability, cost, or developer productivity.

This document should be continuously updated by the agent.
