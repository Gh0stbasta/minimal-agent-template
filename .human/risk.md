## Escalation Rules

The following situations require human approval before implementation:

- Production data deletion
- Security-sensitive architecture changes
- Authentication changes
- Cost increases above defined limits
- Compliance-related decisions
- Third-party integrations with access to sensitive data

## Preferred Mitigation Strategy

Preferred order:

1. Eliminate the risk
2. Reduce the risk
3. Monitor the risk
4. Accept the risk

---

## Risk Review Requirements

Risks must be reviewed when:

- Architecture changes
- Infrastructure changes
- Authentication changes
- New external integrations are added
- New data types are introduced
- Cost model changes
